## 调整「统计药品清单」抽屉的交互节奏

### 目标
让牛舍选择与任务列表之间的联动更自然，不再用显式的「第一步 / 第二步」标题割裂流程；牛舍范围改动后，下方任务列表自动过滤并更新全选/已选计数。

### 改动内容

#### 1. 文件：`src/routes/m.prep.tsx` —— `AggregateDrawer` 组件

- **移除分步标题**
  - 删除「第一步 · 选择牛舍范围」和「第二步 · 选择任务」这两行分步说明文字。
- **重新整合顶部区域**
  - 在抽屉标题「统计药品清单」下方只保留一个统一的牛舍选择栏：左侧放牛舍下拉框按钮，右侧可展示「已选 X / Y」计数。
  - 用一条细线将该栏与下方任务列表分隔开即可，不再用「步骤」概念。
- **保留并沿用联动逻辑**
  - `barnFilter` 变化后，自动通过已有 `useEffect` 清理掉已不在当前牛舍范围内的任务选择。
  - 任务列表仍按 `tasks`（已过滤）渲染；全选/计数基于当前过滤后的任务实时更新。
- **保留底部确认按钮**
  - 「确认统计（n）」按钮维持原样。

#### 2. 视觉细节

- 牛舍下拉框按钮文案保持「不限牛舍 / 已选 n 个牛舍 / 具体牛舍名」。
- 全选复选框保留在当前统一头部右侧，与「已选 X / Y」共处一行。
- 牛舍多选底部抽屉的 UI 与文案保持不变。

### 验收标准
- 抽屉内不再出现「第一步」「第二步」字样。
- 选择牛舍后，任务列表即时刷新，计数随之变化。
- 全选仅作用于当前过滤后的任务。
- 确认统计时仅提交当前过滤后所选中的任务。
