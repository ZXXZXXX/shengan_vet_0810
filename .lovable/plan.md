# 首页图形语言规划

给每类数据配一种固定图形，避免"到处都是圆环/到处都是堆叠条"。规则一旦定下，所有专题按同一套语言执行。

## 图形选型原则（按数据性质）

| 数据性质 | 图形 | 说明 |
| --- | --- | --- |
| 单一比率（1 个百分比） | 半环仪表盘 GaugeArc | 成活率、免疫完成率、顺产率 |
| 构成占比（3-6 类，看结构） | 横向堆叠条 StackedBar | 只保留 1-2 处，用于"总量拆分" |
| 类别对比（离散类目比大小） | 纵向柱状图 ColumnChart | 类型分布、胎型/性别/体重分布 |
| 排名（可排序、类目多） | 排名条 BarList | 死亡原因、淘汰原因、区域牛群规模、费用构成 |
| 时间趋势 | 折线图 LineTrend | 用药费用、发病率、存栏变化 |
| 单值/KPI | MiniStat 数字卡 | 无需图形的绝对值 |
| 状态分流 + 下钻 | 圆环 Donut（全站仅 1 处） | 工单状态 |
| 明细清单 | 列表卡片 | 预警告警 |

## 各专题落位

- 牛群专题：类型分布 → 纵向柱状图（6 类，比大小）；健康分布 → 堆叠条（结构占比，保留唯一堆叠条之一）+ 右侧健康率 MiniStat。
- 死淘专题：牛群构成 → 纵向柱状图（已改）；死亡/淘汰原因 → 排名条（已改）；新增顶部"死淘率"MiniStat。
- 产犊专题：成活率 → 半环仪表盘 + 成活/死亡数字（已改）；犊牛明细（胎型/性别/体重）→ 纵向柱状图（已改）；母牛难易度 → 排名条（已改）。
- 药品专题：费用趋势 → 折线图；当月费用构成 → 排名条；头均费用 → MiniStat。
- 工单专题：状态分流 → 圆环（全站唯一）+ 类型下钻用排名条。
- 疾病统计：牧场/区域发病率排名 → 排名条；疾病大类构成 → 圆环改为堆叠条 + 图例（与工单错开，圆环只留一处）。
- 免疫卡片：完成率 → 半环仪表盘（与现在的进度条统一到仪表盘语言）。
- 运营统计（区域/集团）：KPI → MiniStat；各区域规模 → 排名条。
- 预警告警：保持清单，不加图形。

## 视觉一致性

- 配色统一走 PALETTE：brand 绿=正常/达成，cyan=中性/次类，warning=注意，danger=异常。
- 同一专题内图形不超过 2 种；每张卡片"1 个主图 + 1 组数字"。
- 所有图形共用 Tooltip、图例样式与 tabular-nums 数字排版。
