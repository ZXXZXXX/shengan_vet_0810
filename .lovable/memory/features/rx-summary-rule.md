---
name: 处方摘要（rx）映射规则
description: DiseasePlan.rx 字段的生成规范，用于处方选择器显示
type: feature
---
格式：`处方 N · {任务1摘要} + {任务2摘要} + ...`

每个任务摘要按类型区分：
- 用药类型任务：`药品通用名 · 给药方式`（如 `头孢噻呋 · 肌注`、`利福昔明 · 子宫灌注`）。同通用名多厂家时追加商品名括号区分：`硫酸头孢喹肟（牧全欣）· 乳注`。
- 非用药类型任务：`任务名称 · 任务类型`（如 `修长度 · 护理`、`蹄浴 · 护理`）。

多任务以 ` + ` 连接。剂量、疗程、频次不进摘要，放 `desc` / `duration`。
