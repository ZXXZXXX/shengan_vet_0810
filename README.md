# AI Workspace Hub

这是我的产品架构文件。我需要你根据我的基础色板，以“简约”、“科技”、“ai”为核心风格，设计产品的整体前端界面。
重点界面为：首页（不需要展示产量分析），组织与人员管理，生产对象管理（生产周期与生产作业的功能界面可以不做），仓库管理，配置中心

This project was built with [Lovable](https://lovable.dev).
